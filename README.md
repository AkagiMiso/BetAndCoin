# Bet & Coin

Bet & Coin 为 Minecraft 添加赌场小游戏、筹码和配套装饰，围绕朋友联机与服务器社交活动设计。

## 内容

- **小游戏**：Blackjack、双人 Farkle、轮盘和老虎机。
- **场景装饰**：许愿喷泉、BAR 霓虹灯牌、接待台、红绒隔离带和桌面摆件。
- **筹码**：5 点与 20 点两种面额。

游戏通过桌面模型、动画和音效呈现过程。提供英文和简体中文语言资源。详细玩法将放在独立指南中。

## 版本与环境

| 项目 | 当前版本要求 |
| --- | --- |
| Bet & Coin | 1.0.6 |
| Minecraft Java Edition | 1.16.5 |
| 模组加载器 | Forge 36.2.34 或更高的 1.16.5 版本；开发与测试使用 36.2.34 |
| 必需前置 | GeckoLib 3.0.106，Forge 1.16.5 版 |
| 安装范围 | 客户端与服务端均需安装 |

当前 GeckoLib 依赖范围为 `>= 3.0.106` 且 `< 3.0.107`。其他 Minecraft 版本及 Fabric、NeoForge 版本暂未提供。

## 安装

将 Bet & Coin 和对应 GeckoLib 的 `.jar` 文件放入游戏实例或服务器的 `mods` 文件夹，使用 Forge 启动。联机时，客户端与服务端应保持模组及依赖版本一致。
